# Fahad Hussain — Photonics Engineering

Personal research portfolio covering metasurfaces, polarimetry, optical design, structured light and optical characterisation.

## Add a project

1. Open `index.html` on GitHub and choose **Edit**.
2. Find `ADD A PROJECT` and copy one complete `<article class="project">...</article>` block.
3. Update the title, description, methods and project scope. Set `data-category` to `design`, `light` or `lab`.
4. Upload supporting files into `assets/projects/your-project/` with **Add file → Upload files**.
5. Add links inside the project's `<details>` block, for example:

```html
<p><a href="assets/projects/your-project/report.pdf">Read report</a></p>
<p><a href="https://github.com/fahadh3/your-project">View code</a></p>
<img src="assets/projects/your-project/result.png" alt="Describe the result" style="max-width:100%;height:auto" loading="lazy">
```

6. Update the initial `project-count` text and commit. GitHub Pages will republish the site when configured for the main branch.

Project descriptions reflect the supplied CV. No project reports, images or source code have been invented. The optical illustration is conceptual, not simulation data.

## Hosting

This is a standalone static website with no build or installation step. Enable **Settings → Pages → Deploy from a branch → main → /(root)**. For Vercel or Netlify, use the repository root as the publish directory and no build command.

## Editing other sections

Edit the research, education and contact sections directly in `index.html`. Keep incoming roles labelled as incoming until they begin. The old portfolio history should remain in the private original repository rather than being copied here.
